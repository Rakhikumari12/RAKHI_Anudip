# 🚔 Power BI Crime Analysis Dashboard  

## 📊 Overview  
This Power BI dashboard provides a comprehensive analysis of crime data, including crime trends, distribution by location, victim demographics, and law enforcement deployment. The visualizations help identify patterns, high-crime areas, and key insights for decision-making.  

---

## 🔍 *Key Visualizations and Their Purpose*  

### 1️⃣ *Crime Reports Over Time*  
- *Visualization Used:* Line Chart  
- *Why Used?*  
  - Helps track monthly trends in crime reports.  
  - Identifies seasonal patterns and sudden spikes or drops in crime.  
- *Fields Used:*  
  - Month (X-Axis)  
  - Count of Crime Description (Y-Axis)  

---

### 2️⃣ *Crime Distribution by Crime Domain*  
- *Visualization Used:* Pie Chart  
- *Why Used?*  
  - Provides a breakdown of crimes into different categories (e.g., Violent Crime, Fire Accidents).  
  - Helps in resource allocation based on crime type.  
- *Fields Used:*  
  - Crime Domain (Legend)  
  - Count of Crime Description  

---

### 3️⃣ *Crime Reports by City*  
- *Visualization Used:* Bar Chart  
- *Why Used?*  
  - Displays the number of crime reports across various cities.  
  - Identifies high-crime cities to focus law enforcement efforts.  
- *Fields Used:*  
  - City (Y-Axis)  
  - Sum of Report Number (X-Axis)  

---

### 4️⃣ *Total Crime Count Card 
- *Visualization Used:* Card  
- *Why Used?*  
  - Displays the total number of crime incidents in a single number.  
  - Quickly provides a high-level summary of crime occurrences.  
- *Fields Used:*  
  - Count of Crime Code  

---

### 5️⃣ *Weapons Used in Crimes*  
- *Visualization Used:* Line Chart  
- *Why Used?*  
  - Tracks the frequency of different weapons used in crimes.  
  - Highlights trends in weapon usage over time.  
- *Fields Used:*  
  - Weapon Used (X-Axis)  
  - Sum of Report Number (Y-Axis)  

---

### 6️⃣ *Victim Demographics by Weapon Used*  
- *Visualization Used:* Stacked Bar Chart  
- *Why Used?*  
  - Compares the number of male and female victims for each weapon type.  
  - Provides insights into how different weapons impact different demographics.  
- *Fields Used:*  
  - Weapon Used (X-Axis)  
  - Victim Gender (Legend)  
  - Sum of Victim Age (Y-Axis)  

---

### 7️⃣ *Crime Breakdown by Type*  
- *Visualization Used:* Pie Chart  
- *Why Used?*  
  - Displays the distribution of specific crime types (e.g., Burglary, Fraud, Assault).  
  - Helps in identifying the most common types of crime.  
- *Fields Used:*  
  - Crime Description (Legend)  
  - Sum of Report Number  

---

### 8️⃣ *Crimes by Time of Occurrence*  
- *Visualization Used:* Stacked Bar Chart  
- *Why Used?*  
  - Shows when different crime types occur the most (morning, afternoon, night).  
  - Helps in planning police patrols effectively.  
- *Fields Used:*  
  - Time of Occurrence (X-Axis)  
  - Crime Description (Legend)  
  - Sum of Report Number  

---

### 9️⃣ *Case Closure Rate by Year*  
- *Visualization Used:* Bar Chart  
- *Why Used?*  
  - Displays the number of cases closed per year.  
  - Helps in tracking law enforcement efficiency over time.  
- *Fields Used:*  
  - Year (X-Axis)  
  - Count of Case Closed (Y-Axis)  

---

### 🔟 *Police Deployment by Crime & City*  
- *Visualization Used:* Map Chart  
- *Why Used?*  
  - Provides a geographic distribution of police deployment across different crime types.  
  - Helps in understanding how resources are allocated regionally.  
- *Fields Used:*  
  - City (Map Locations)  
  - Crime Description (Legend)  
  - Sum of Police Deployed  

---

## 📌 *Key Takeaways*  
✔ Crime rates fluctuate throughout the year, with notable decreases in certain months.  
✔ Violent crimes account for the highest percentage of reported cases.  
✔ Delhi and Mumbai report the highest number of crime incidents.  
✔ Certain weapons like knives and firearms are used more frequently.  
✔ The highest number of crimes occur at night and early morning hours.  
✔ Police deployment varies significantly by region, with hotspots in high-crime areas.
